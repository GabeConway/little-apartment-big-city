## Game architecture (`src/game/`)
No npm deps (React only). All art in-code (CSP). Logical view **384×224** (24×14 tiles of 16px) — raised from 320×192 for finer look (user tuned: 448×256 felt too zoomed-out); canvas scales at integer device-pixel multiples (hard rule below).

## Systems (quick map)
- **Fishing gate**: locked until talk to **Genji** on shore (`save.canFish`). All casts funnel through `startCast`. **Minigame = the classic Stardew-lite catch-zone bar** (`fishing.ts`: hold E to raise the green zone, keep the darting fish inside until the progress meter fills; `ZONE_H` fixed). First cast ever shows a one-time **HOW TO FISH** explainer (gated by `storySeen 'fish-howto'`). *(An overhauled stamina/tension/lunge variant was tried and reverted — keep the catch-zone bar.)* **Rod tiers** (`RODS`/`rodInfo`, `save.fishRod`): tier 0 = Genji's starter (gift); tier 1 = **Genji's Carbon Rod** (¥6,000, his `genji` tackle shop, opens once `canFish`). The rod does **not** change the minigame — it just biases the bite roll so the rarer/bigger fish (value ≥500) bite far more often (stacks with `shrineLuck`).
- **Economy**: fishing, shift ¥1800/day, vending ¥150 "Diet Doctor Peepis" can (+12 en), minerals, pawn daily stock, sketchy Jimmy daily deal. **Rebalanced (2026-06-29/30)** so money is harder-won and big purchases land as goals: ore values trimmed (Void Opal 900→750, Astral Stone 2200→1600), **fewer ore nodes** (`oreCount` formula cut so striking a vein feels like an event), vaults **rarer & deeper** (`VAULT_MIN_FLOOR` 3→4, `VAULT_CHANCE` 0.07→0.05, chest pays `1800 + depth*350`), geode **jackpot** 5000→3000. The **car** is now the prestige tier (¥75k→¥100k, **gated**: needs the boat owned + the `first-delivery` achievement); the new **bicycle** (¥9k) is the cheap entry vehicle. New **luxury money sinks** (below) absorb late-game wealth.
- **Phone (replaces the old bag menu)**: open with **P** / 📱 HUD button / Y·Start (key is `'p'` in `engine.ts`); `overlay {type:'menu', tab: PhoneApp, thread?}`. Phone-shaped shell: status bar (clock/day/**energy-as-battery**), home screen (clock widget + app grid), apps = **Bag** (boxed/placed lists + **ARRANGE ROOM** button + fish/pocket), **Messages**, **Journal** (📓 — live CURRENT GOALS checklist + cryptic NEXT STEPS hints + day/cash/fish footer, all derived from save state so a lost player can check "what now"; built to extend with real missions), **ZamaZonk** (order furniture), **Trophies** (achievements), **Settings** (wallet + Save&Quit + Developer codes), **Codes** (cheat input). **No Wallet app** (wallet lives in Settings). Esc/B steps back to home then closes; P/Y closes outright. Tap home-bar to pocket. App-icon badges live on a non-clipped outer wrapper (inner tile clips the icon).
- **Messages**: `MESSAGES` catalog (data.ts) of company/people texts; each delivered once when its `when(MsgCtx)` predicate is met. `syncMessages(s)` runs on **scene enter, waking, and game start**; appends to `save.messages` (deduped by id). `pushMessage` adds one-off (non-catalog) texts — used for ZamaZonk receipts. Unread → green dots + HUD badge (`unreadCount`); opening a thread marks it read. Triggers (post-trim): landlord welcome (day-1, time-gated ~7:30), Grandma (day≥2), store welcomes off `metStores` (Doki Doki/Konbini, after first interaction takes your number), konbini job offer (`leftKonbiniAt`+1h), konbini lottery results (`pushMessage`), ZamaZonk welcome (after the **island poster** sets `zamazonkApp`) + per-order receipts. **Removed as too chatty**: Tex/Kojima/Lulu/DJ-Tanuki/Manager-wand/Genji + the furniture-milestone journal beats.
- **ZamaZonk** (the evil everything-store megacorp): phone app lists base furniture you don't own; **order** = pay `price + ¥300 ZamaPrime` now, item arrives **next morning** boxed via `fulfillDeliveries(s)` (called in `finishSleep`). `save.orders[]` = in-transit; order + delivery each push a ZamaZonk text. Logo asset `public/images/zamazonk-logo.png` (`ZAMAZONK_LOGO`, `object-contain` on dark tile so it isn't cropped).
- **Furniture placement = Arrange mode** (drag-and-drop; replaces the old `PLACEMENT_SPOTS` picker): phone Bag → **ARRANGE ROOM** (at home) → `arrangeRef` mode. A transparent pointer-capture surface over the canvas + a DOM tray of boxed items + a bin; the canvas draws a floor grid + a green/red drag **ghost**. Drag a tray chip onto a valid floor tile to place; drag a placed item to move it, or to the bin to box it. Tap-select + tap-place also works (touch/keyboard-less). Validity = `placeableAt` (footprint of interior floor cells free; wall items on the top wall row). Movement frozen; Esc/B exits. Effects (bed/microwave/fridge/AC/kotatsu) still only when PLACED; ending = all 10 base placed. (The old `PLACEMENT_SPOTS` picker + `freeSpotsFor`/`spotLabelAt` helpers were fully removed — Arrange mode + `placeableAt` superseded them.)
- **Day/night** (`nightT`+`morningT`, applied in the draw loop after entities): `TIME_RATE` 3.5 game-min/real-sec (~5.5 real-min/day). **Night** ramps 17:00–20:00 → cool blue wash (outdoor 0.5α) + cyan sky band; **lit signs re-light over the tint** (`relightSigns`: additive bloom + repaint, so neon shines instead of dimming — a sign is "lit" if it blinks / has a border / sits on a solid `#` panel). **Morning** 7:00→9:30 = warm golden `soft-light` wash + low-sun rake (outdoor only). 2 AM collapse → wake home. HUD clock reddens past midnight. **Perf**: the night sky band + morning sun rake are cached `CanvasGradient`s (`skyGradRef`/`sunGradRef`, built once, alpha modulated via `globalAlpha`) — not rebuilt per frame; and the sign re-light now blits cached sprites (see signs perf note below), so night no longer costs a full char-by-char repaint.
- **Sleep / collapse flow** (3 steps via `pendingWakeRef`): `doSleep` snapshots `s.today` into `DayRecap` BEFORE `passNight` → `sleep` overlay (ordinary fade / collapse "OUT COLD" waits for click) → `finishSleep` runs passNight + opens **`endday` recap** overlay → `closeEndDay`. Per-day tally `save.today` (`DayLog`).
- **Vehicles** (`VEHICLES` in data.ts): **bicycle** ¥9k (cheap entry tier), **car** ¥100k (the gated prestige tier — only buyable once you **own the boat AND have the `first-delivery` achievement**; world entity `save.carPos`, board/drive 2.4×/park; TOW ¥500 at garage), **boat** ¥22k → skiff menu (Sumikawa Bay or Kiwami Island). While driving the car **bobs/shimmies + trails exhaust puffs**, and a **cute WebAudio motor** putters with pitch/volume that glide up under acceleration and idle when stopped (`engine`/`engineSet`/`engineStop`, very quiet, honors mute, stopped on park/menu/unmount/title).
- **Island (Kiwami)** — *overhauled 2026-06-27, bigger & richer (28×15, scrolls)*: a real island with a smoking **volcano** (crater glow, additive, always-on pulse via the cached `glow()` sprite), a **turquoise lagoon** (`t-lagoon`, the tropical-fishing water), two wooden **docks** (`t-dock`, walkable — the skiff moors at the west one, lands you at (3,7); a pier reaches into the lagoon), a jungle of coconut palms + **banana palms** (`t-banana`), and a sandy beach ring. **New activities**: the **hot spring / onsen** (`onsen` interactable on the `H` tiles, steam puffs in the draw loop) — soak once/day (`save.onsenDay`) to refill energy to full **and** gain the `warm` buff free; **banana palms** shake for a +8-energy snack once/day (reuses `palmDay`/`palmsShaken`); a hidden **message in a bottle** (`island-bottle`, far SE sand `b` tile) — a one-time secret (`storySeen 'island-bottle'`) paying ¥1,200 + cryptic lore (signed "K", ties into the discovery theme). Still: Lulu's Tiki Bar (`tiki` shop, npc at (7,10)), coconut palms (`save.coconuts`), the ZamaZonk poster. New in-code sprites: `t-lagoon`/`t-rock`/`t-volcano`/`t-hotspring`/`t-dock`/`t-banana`/`t-bottle`. **(Built in-code, not sprite-ai — the toolkit was out of tokens; see progress log.)**
- **Backrooms chain** (now gated): konbini freezer door is a "cold wall" until `save.backroomsUnlocked` — set by bringing **The Big Guy** in Club Kaiju a **Diet Mountain Doofert** (he then reveals the portal). Then backrooms (Manager, Jean-Pierre) → mines: a **multi-floor roguelike descent**. `mineLayoutFor(s, floor)` reseeds **per day AND per floor** (seed = day+floor); deeper = more ore, rarer ore, more/tougher crawlers. **Floor is a runtime ref** (`mineFloorRef`, not saved): the **descend ladder** is placed at a **seeded-random floor tile each floor/day** (`mineLayoutFor` returns `down`; `mineDownRef`, drawn as `t-ladder-down`, handled dynamically in `handleInteract` — NOT a static map interactable; reserved so no ore/crawler covers it). Using it goes floor+1 and drops you at the top of the new floor (depth banner toast); the **ascend ladder** (`t-ladder-up`, fixed at 1,1) climbs **all the way back to the surface** from any depth. A reload resumes at floor 1. **6 minerals** (coal/iron/shard/crystal/opal/starstone) each with `minFloor` (deep ore gated by depth) + `hardness` (gated by pickaxe `power`). **Pickaxe tiers** (`PICKAXES` 0–3: bare hands→Tin→Steel→Diamond; lower energy cost, bonus-yield chance, higher power) bought from the Manager. **Geodes** = sealed nodes (need power≥`GEODE_HARDNESS`); mining adds to `save.geodes`, crack at the Manager (`crackGeode`) for a weighted random reward. **Daily challenge** (`mineChallengeFor`, seeded by day, shown on the mine HUD) nudges the whole day (Crystal Rush / Infested / Rich Veins / Geode Day / The Deep Calls / Quiet Day). **Mining streak** (`enterMineStreak`, `save.mineStreak`/`mineLastDay`) adds a small luck bonus for consecutive days. **Crawler kinds** (`normal`/`fast`/`tank`/`gold` — `CRAWLER_HP`/`CRAWLER_SPD` in the main file; tougher kinds gated by depth; the rare gold crawler pays out big on kill). **Weapons** (best→worst): **AK-67** (`save.gun`, full-auto: hold the action button, fast piercing bullets — fired in the update loop via `input.actionHeld`+`gunCooldownRef`; **unlocked only by reaching floor `GUN_UNLOCK_FLOOR`=10**, `save.deepestFloor`, then sold by the Manager ¥25,000) > **upgraded wand** (`save.wand2`: piercing bolts, wider light) > **wand** (`save.wand`) > bare hands. Wand **or** gun required to descend. **Combat is now auto-defend** (`autoFireRef`): whichever weapon you hold **auto-targets and fires at the nearest crawler on its own cadence**, so the action button stays free for mining — you no longer have to choose between swinging the pick and fending off crawlers. Mineral-only CRAFT — recipes are **pinned to a depth/pickaxe tier** so the rares unlock as a progression ladder: neon (Tin+floor2) → kotatsu (Tin+floor2) → aquarium (Steel+floor4, opal) → arcade (Diamond+floor6, starstone, endgame). Flashlight darkness vignette (radius widens with wand2/gun). **Perf**: the vignette's radial gradient is **cached per light-radius** (`mineDarkRef`) — built once centered at (0,0) and `translate`d to the player each frame, with the lantern flicker riding on `globalAlpha` instead of re-baking the radius. The old code called `createRadialGradient` every frame (the KB-banned per-frame pattern); `lr` only changes when you gain a wand/gun, so it's now effectively built once. Depth milestones at floors 5/10 (`reachFloor` → achievements `delver`/`abyss` + the gun-unlock Manager text). **KO at 0 energy from a crawler** → Jean-Pierre carries you home; on waking he's stood in your apartment (a scripted `cutsceneRef` actor), talks, then **walks to the door and out before you regain control** (input locked the whole time, animated in the update loop, drawn y-sorted with the NPCs). The rescue cutscene is now **generalized** (`pendingWakeRef.rescuer = 'jean' | 'yoshi'`): passing out at the **2 AM collapse while on the shrine grounds** → **Yoshi** walks you home instead (same mechanism, `npc-miko` actor + her own dialog). **Cheat `im god`** (`save.god`) makes crawlers unable to damage you.
- **Nightclub (Club Kaiju)**: "The Big Guy" patron (give him a Doofert to unlock the backrooms). On arrival the player **materializes in datamoshed glitch-scanlines** (`parisGlitchRef`, ~1.9s "hacked into the map"). The **Eiffel Tower is one big sprite** (`atlas['eiffel-big']`, 112×108, concave legs + grand arch + two decks + spire, carved with `destination-out`) blitted over a big open sky in the paris draw block — NOT tiles (the old tile tower read as a crane claw; the paris grid was reworked so sky fills rows 0-7 and the tower rises into it). Jean-Pierre the tourist is from there.
- **Yakuza Downtown toll**: enforcers (`npc-yakuza`) block the city→badtown alley until `save.gangPaid`. Interact → ShopFrame choice (PAY ¥5,000 / WALK AWAY) → **'fade' transition**, they vanish. Same yakuza run the **casino**.
- **Casino (Kinryū Lounge)**: interior off Downtown (gold marquee facade `t-casino-front`, **door at badtown x14-15** in the 28-wide strip). Dealer NPC → lobby → **Blackjack** (3:2, dealer stands 17) + **Slots** (3-reel) + **Roulette** (single-zero European wheel; outside bets pay even, a number pays 35:1; `roulettePayout`/`spinRoulette`). Bet `s.money`. **Progressive slots jackpot** (2026-07-02): `jackpotFor(s)` (state.ts, seeded/deterministic, **memoized** — it's re-derived every render incl. the 80ms reel ticks — and **capped at `JACKPOT_CAP` ¥50,000** so veteran saves meeting the feature don't get a silly payout) = ¥4,000 base + ¥400–899/day since `save.jackpotDay` (0 = never hit); triple-7s (`isTripleSeven`/`SLOT_SEVEN` beside `slotPayout` — the symbol index lives in ONE place) pay it ON TOP of the 50× line, then `jackpotDay = day` resets the pot (`jackpot` ach "Neon Rain"). **Slots/roulette settles are shared fns** (`settleSlots`/`settleRoulette(silent)`): the outcome is fixed at PULL/SPIN, and `startSlots`/`startRoulette` settle a still-flying spin silently before resetting — bailing out of the panel mid-spin can never eat a bet or the pot (previously `startSlots` cleared the interval and swallowed the result; `startRoulette` leaked the old interval). Shown on the slots panel marquee + the lobby's slots button; a Kawamachi Bulletin fires each morning the pot crosses another ¥10,000 line (deterministic diff of `jackpotFor` day vs day−1, in `finishSleep`). **Hidden backroom** (2026-07-02; gate raised 15 → **30** same day, owner call): every winning bet at any of the **four** games ticks `save.casinoWins` (`countCasinoWin`); at 30 (`BACKROOM_WINS`/`backroomOpen`) the **velvet curtain** opens into **`backroom` (Kinryū Backroom, scene #21)** where **the Kinryū Boss** (`kinryu-boss`, `npc-yakuza` sprite) comps you a one-time ¥10,000 (`storySeen 'backroom-met'`). ## Hard rules
- Game has own achievement system in `lab-save` — self-contained.
- Doors ≥2 tiles wide (hitbox alignment).
- Canvas backing = integer multiple of 384×224 device px (`fit()` + `ctx.setTransform(scale)`); CSS-stretching blurs on Retina.
- **Layout fills viewport when `filled` (= `isFullscreen || isDesktopApp`)**; else sits in centered `max-w-[1000px]` box. `isDesktopApp` = Tauri shell detected via `'__TAURI_INTERNALS__' in window`. Desktop/native window launches OS-fullscreen (`tauri.conf.json` `fullscreen: true`), where `document.fullscreenElement` is null, so `isDesktopApp` (not `isFullscreen`) makes native app fill its window and integer-upscale canvas.
- **In-page fullscreen buttons (HUD ⛶ + title GO FULLSCREEN) hidden when `isDesktopApp`** — OS window owns fullscreen there. Stay for web/mobile.
- **Title screen shows ✕ QUIT GAME only when `isDesktopApp`** — closes window via `__TAURI_INTERNALS__.invoke('plugin:window|close', {label:'main'})` (dependency-free; keeps `src/game/` React-only). Needs `core:window:allow-close` in `src-tauri/capabilities/default.json`.
- Warp targets land beside doors, not on them.
- Save shape changes: loader merges over `newSave()`; only migrations need `v` check.
- **`src/game/` imports only `react` + sibling game files** — keep dependency-free.
- **Assets are absolute paths** (`/images`, `/music`, `/sfx`) — resolve at app root in Tauri webview. Don't hardcode origins.
- **Controller**: `Input.pollGamepad()` called once per update tick (top of `update` in `LittleApartmentGame.tsx`). Standard Gamepad mapping, edge-detected; reuses virtual-dir path so shares keyboard's "most recent wins" ordering. Dependency-free (Gamepad API = webview global).
- **Persistence is `localStorage`** (`lab-save`, `lab-music-muted`) — works in every webview.

## Fonts
Game uses `font-retro` (Press Start 2P) + `font-pixel` (VT323), self-hosted via `@fontsource/*` and imported in `src/index.css` (NOT Google Fonts CDN — so work offline in native builds).
**Naganoshi** — Japanese pixel font (OFL 1.1, GGBotNet) — self-hosted in `public/fonts/` (`@font-face` in `src/index.css`; `font-jp` Tailwind family; license bundled as `public/fonts/Naganoshi-License.txt`). Source archive (not bundled): `assets/fonts/Naganoshi_Font_0_4.zip`. Canvas store signs render **per character**: kana/kanji in Naganoshi, Latin/digits/punctuation in bold monospace (Naganoshi has no Latin glyphs, so whole-string switch would tofu English parts). See `measureRun`/`charFont` in the sign-drawing block of `LittleApartmentGame.tsx`. Canvas text doesn't auto-fetch webfont — `document.fonts.load("16px 'Naganoshi'")` kicked in the play-loop effect. **Perf (important)**: each sign's panel+border+text is rendered to an offscreen canvas **once** (`signSpriteRef`, keyed by the sign object) and blitted every frame — the old code walked every glyph with a per-char `ctx.font` switch + `measureText` **every frame, in both the base pass and the night re-light pass**, which was the framerate sink (font-switching on canvas is very slow; worst at night with the double pass). Blink-off dims the cached sprite via `globalAlpha` instead of recolouring. **Crispness**: the sprite is rendered at the live **device scale** (`scaleRef.current * RR`) and blitted back at logical size (1:1 device mapping) — a 1× sprite upscaled by the canvas transform looked blurry; the cache entry stores its scale and rebuilds if it changes. The cache is also cleared once `document.fonts.load(...).then()` resolves so signs rebuilt before the face loaded don't freeze the fallback glyphs. Don't reintroduce per-frame glyph walking, and don't cache at 1×.

## Display / scaling
Title screen **DISPLAY** button → panel of scale options (AUTO / 1×–6×), persisted as `lab-scale`. The `fit()` effect: **AUTO** = biggest integer multiple of 384×224 fitting frame (layout box). **N×** = forced scale, clamped so can't exceed screen — in **filled** layout (fullscreen/native) frame *is* viewport so it's cap; in **windowed** web box capped at 1000px, so forced scale clamped to *viewport* (`window.innerWidth/innerHeight`) instead and `boxW` grows box past 1000 to fit (never shrinks below 1000 — would crowd HUD). Without this, every scale above 2× clamped to box, looked identical. (No separate "resolution" axis — logical viewport fixed at 384×224 by map design; output res = scale × that.)
