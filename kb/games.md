## Game architecture (`src/game/`)
No npm deps (React only). All art in-code (CSP). Logical view **384×224** (24×14 tiles of 16px) — raised from 320×192 for finer look (user tuned: 448×256 felt too zoomed-out); canvas scales at integer device-pixel multiples (hard rule below).

## Systems (quick map)
- **Fishing gate**: locked until talk to **Genji** on shore (`save.canFish`). All casts funnel through `startCast`.
- **Economy**: fishing, shift ¥1800/day, vending ¥150 "Diet Doctor Peepis" can (+12 en), minerals, pawn daily stock, sketchy Jimmy daily deal.
- **Phone (replaces the old bag menu)**: open with **P** / 📱 HUD button / Y·Start (key is `'p'` in `engine.ts`); `overlay {type:'menu', tab: PhoneApp, thread?}`. Phone-shaped shell: status bar (clock/day/**energy-as-battery**), home screen (clock widget + app grid), apps = **Bag** (boxed/placed lists + **ARRANGE ROOM** button + fish/pocket), **Messages**, **ZamaZonk** (order furniture), **Trophies** (achievements), **Settings** (wallet + Save&Quit + Developer codes), **Codes** (cheat input). **No Wallet app** (wallet lives in Settings). Esc/B steps back to home then closes; P/Y closes outright. Tap home-bar to pocket. App-icon badges live on a non-clipped outer wrapper (inner tile clips the icon).
- **Messages**: `MESSAGES` catalog (data.ts) of company/people texts; each delivered once when its `when(MsgCtx)` predicate is met. `syncMessages(s)` runs on **scene enter, waking, and game start**; appends to `save.messages` (deduped by id). `pushMessage` adds one-off (non-catalog) texts — used for ZamaZonk receipts. Unread → green dots + HUD badge (`unreadCount`); opening a thread marks it read. Triggers (post-trim): landlord welcome (day-1, time-gated ~7:30), Grandma (day≥2), store welcomes off `metStores` (Doki Doki/Konbini, after first interaction takes your number), konbini job offer (`leftKonbiniAt`+1h), konbini lottery results (`pushMessage`), ZamaZonk welcome (after the **island poster** sets `zamazonkApp`) + per-order receipts. **Removed as too chatty**: Tex/Kojima/Lulu/DJ-Tanuki/Manager-wand/Genji + the furniture-milestone journal beats.
- **ZamaZonk** (the evil everything-store megacorp): phone app lists base furniture you don't own; **order** = pay `price + ¥300 ZamaPrime` now, item arrives **next morning** boxed via `fulfillDeliveries(s)` (called in `finishSleep`). `save.orders[]` = in-transit; order + delivery each push a ZamaZonk text. Logo asset `public/images/zamazonk-logo.png` (`ZAMAZONK_LOGO`, `object-contain` on dark tile so it isn't cropped).
- **Furniture placement = Arrange mode** (drag-and-drop; replaces the old `PLACEMENT_SPOTS` picker): phone Bag → **ARRANGE ROOM** (at home) → `arrangeRef` mode. A transparent pointer-capture surface over the canvas + a DOM tray of boxed items + a bin; the canvas draws a floor grid + a green/red drag **ghost**. Drag a tray chip onto a valid floor tile to place; drag a placed item to move it, or to the bin to box it. Tap-select + tap-place also works (touch/keyboard-less). Validity = `placeableAt` (footprint of interior floor cells free; wall items on the top wall row). Movement frozen; Esc/B exits. Effects (bed/microwave/fridge/AC/kotatsu) still only when PLACED; ending = all 10 base placed. (The old `PLACEMENT_SPOTS` picker + `freeSpotsFor`/`spotLabelAt` helpers were fully removed — Arrange mode + `placeableAt` superseded them.)
- **Day/night** (`nightT`+`morningT`, applied in the draw loop after entities): `TIME_RATE` 3.5 game-min/real-sec (~5.5 real-min/day). **Night** ramps 17:00–20:00 → cool blue wash (outdoor 0.5α) + cyan sky band; **lit signs re-light over the tint** (`relightSigns`: additive bloom + repaint, so neon shines instead of dimming — a sign is "lit" if it blinks / has a border / sits on a solid `#` panel). **Morning** 7:00→9:30 = warm golden `soft-light` wash + low-sun rake (outdoor only). 2 AM collapse → wake home. HUD clock reddens past midnight.
- **Sleep / collapse flow** (3 steps via `pendingWakeRef`): `doSleep` snapshots `s.today` into `DayRecap` BEFORE `passNight` → `sleep` overlay (ordinary fade / collapse "OUT COLD" waits for click) → `finishSleep` runs passNight + opens **`endday` recap** overlay → `closeEndDay`. Per-day tally `save.today` (`DayLog`).
- **Vehicles**: car ¥75k (world entity `save.carPos`, board/drive 2.4×/park; TOW ¥500 at garage); boat ¥22k → skiff menu (Sumikawa Bay or Kiwami Island).
- **Island**: Lulu's Tiki Bar; 3 palms drop coconut/day (`save.coconuts`); tropical fish.
- **Backrooms chain** (now gated): konbini freezer door is a "cold wall" until `save.backroomsUnlocked` — set by bringing **The Big Guy** in Club Kaiju a **Diet Mountain Doofert** (he then reveals the portal). Then backrooms (Manager, Jean-Pierre) → mines: a **multi-floor roguelike descent**. `mineLayoutFor(s, floor)` reseeds **per day AND per floor** (seed = day+floor); deeper = more ore, rarer ore, more/tougher crawlers. **Floor is a runtime ref** (`mineFloorRef`, not saved): the **descend ladder** is placed at a **seeded-random floor tile each floor/day** (`mineLayoutFor` returns `down`; `mineDownRef`, drawn as `t-ladder-down`, handled dynamically in `handleInteract` — NOT a static map interactable; reserved so no ore/crawler covers it). Using it goes floor+1 and drops you at the top of the new floor (depth banner toast); the **ascend ladder** (`t-ladder-up`, fixed at 1,1) climbs **all the way back to the surface** from any depth. A reload resumes at floor 1. **6 minerals** (coal/iron/shard/crystal/opal/starstone) each with `minFloor` (deep ore gated by depth) + `hardness` (gated by pickaxe `power`). **Pickaxe tiers** (`PICKAXES` 0–3: bare hands→Tin→Steel→Diamond; lower energy cost, bonus-yield chance, higher power) bought from the Manager. **Geodes** = sealed nodes (need power≥`GEODE_HARDNESS`); mining adds to `save.geodes`, crack at the Manager (`crackGeode`) for a weighted random reward. **Daily challenge** (`mineChallengeFor`, seeded by day, shown on the mine HUD) nudges the whole day (Crystal Rush / Infested / Rich Veins / Geode Day / The Deep Calls / Quiet Day). **Mining streak** (`enterMineStreak`, `save.mineStreak`/`mineLastDay`) adds a small luck bonus for consecutive days. **Crawler kinds** (`normal`/`fast`/`tank`/`gold` — `CRAWLER_HP`/`CRAWLER_SPD` in the main file; tougher kinds gated by depth; the rare gold crawler pays out big on kill). **Weapons** (best→worst): **AK-67** (`save.gun`, full-auto: hold the action button, fast piercing bullets — fired in the update loop via `input.actionHeld`+`gunCooldownRef`; **unlocked only by reaching floor `GUN_UNLOCK_FLOOR`=10**, `save.deepestFloor`, then sold by the Manager ¥25,000) > **upgraded wand** (`save.wand2`: piercing bolts, wider light) > **wand** (`save.wand`) > bare hands. Wand **or** gun required to descend. Mineral-only CRAFT — recipes are **pinned to a depth/pickaxe tier** so the rares unlock as a progression ladder: neon (Tin+floor2) → kotatsu (Tin+floor2) → aquarium (Steel+floor4, opal) → arcade (Diamond+floor6, starstone, endgame). Flashlight darkness vignette (radius widens with wand2/gun). Depth milestones at floors 5/10 (`reachFloor` → achievements `delver`/`abyss` + the gun-unlock Manager text). **KO at 0 energy from a crawler** → Jean-Pierre carries you home; on waking he's stood in your apartment (a scripted `cutsceneRef` actor), talks, then **walks to the door and out before you regain control** (input locked the whole time, animated in the update loop, drawn y-sorted with the NPCs). **Cheat `im god`** (`save.god`) makes crawlers unable to damage you.
- **Nightclub (Club Kaiju)**: "The Big Guy" patron (give him a Doofert to unlock the backrooms). DJ Tanuki present; promo texts trimmed (he no longer texts you). **Overhauled visuals**: the dance floor ripples 4 color frames by tile position (`t-dance-0..3`, selected `(tx+ty*2+t*5)&3` in the tile loop); a dedicated nightclub draw block dims the room then adds sweeping additive colored spotlights from the DJ booth + a disco-ball glow (**no strobe** — seizure risk). **Lighting perf**: glows are pre-rendered once to cached canvases (`glowSpriteRef`, a `rgb→canvas` map) and blitted with `drawImage`+`globalAlpha`; the first pass used `createRadialGradient`+full-screen fill per beam per frame and tanked FPS — never do that. The crowd are `DANCER_IDS` (`dancer`..`dancer4`) folded into `WANDER_IDS` so they bob in place (draw-time hop + always-animate) and only **shuffle ~22%** of decision ticks (they mostly stay put — non-dancers still roam at 60%). Interior `バー`/`KAIJU` neon (`SCENE_SIGNS.nightclub`) mounted on the **back wall row (y0)** so they don't overlap the bartender/DJ.
- **Downtown lamps**: the `t-streetlamp` posts cast a soft warm cached-glow (same `glowSpriteRef` system) from each lamp head — the badtown draw block scans visible tiles for `L` and blits a faint flickering glow.

## Hard rules
- Game has own achievement system in `lab-save` — self-contained.
- Doors ≥2 tiles wide (hitbox alignment).
- Canvas backing = integer multiple of 384×224 device px (`fit()` + `ctx.setTransform(scale)`); CSS-stretching blurs on Retina.
- **Layout fills viewport when `filled` (= `isFullscreen || isDesktopApp`)**; else sits in centered `max-w-[1000px]` box. `isDesktopApp` = Tauri shell detected via `'__TAURI_INTERNALS__' in window`. Desktop/native window launches OS-fullscreen (`tauri.conf.json` `fullscreen: true`), where `document.fullscreenElement` is null, so `isDesktopApp` (not `isFullscreen`) makes native app fill its window and integer-upscale canvas.
- **In-page fullscreen buttons (HUD ⛶ + title GO FULLSCREEN) hidden when `isDesktopApp`** — OS window owns fullscreen there. Stay for web/mobile.
- **Title screen shows ✕ QUIT GAME only when `isDesktopApp`** — closes window via `__TAURI_INTERNALS__.invoke('plugin:window|close', {label:'main'})` (dependency-free; keeps `src/game/` React-only). Needs `core:window:allow-close` in `src-tauri/capabilities/default.json`.
- Warp targets land beside doors, not on them.
- Save shape changes: loader merges over `newSave()`; only migrations need `v` check.
- **`src/game/` imports only `react` + sibling game files** — keep dependency-free.
- **Assets are absolute paths** (`/images`, `/music`, `/sfx`) — resolve at app root in Tauri webview. Don't hardcode origins.
- **Controller**: `Input.pollGamepad()` called once per update tick (top of `update` in `LittleApartmentGame.tsx`). Standard Gamepad mapping, edge-detected; reuses virtual-dir path so shares keyboard's "most recent wins" ordering. Dependency-free (Gamepad API = webview global).
- **Persistence is `localStorage`** (`lab-save`, `lab-music-muted`) — works in every webview.

## Display / scaling
Title screen **DISPLAY** button → panel of scale options (AUTO / 1×–6×), persisted as `lab-scale`. The `fit()` effect: **AUTO** = biggest integer multiple of 384×224 fitting frame (layout box). **N×** = forced scale, clamped so can't exceed screen — in **filled** layout (fullscreen/native) frame *is* viewport so it's cap; in **windowed** web box capped at 1000px, so forced scale clamped to *viewport* (`window.innerWidth/innerHeight`) instead and `boxW` grows box past 1000 to fit (never shrinks below 1000 — would crowd HUD). Without this, every scale above 2× clamped to box, looked identical. (No separate "resolution" axis — logical viewport fixed at 384×224 by map design; output res = scale × that.)
